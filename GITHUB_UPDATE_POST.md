## Antivirus false positives, explained and fixed

v1.0.0 was flagged by 6 of 70 engines on VirusTotal. Every detection was a
generic ML/heuristic verdict — `Trojan:Win32/Wacatac.B!ml`, `Static AI -
Suspicious PE`, `BehavesLike.Win64.Dropper`, and two bare `MALICIOUS` results.
No engine named a malware family, and no signature-based engine detected
anything.

The cause was packaging, not behaviour. A PyInstaller one-file build embeds a
compressed payload, unpacks it into `%TEMP%` at launch and executes a second
binary from there — which is what a dropper does.

## Fixed

The in-app update check compared the release tag against a hardcoded
`APP_VERSION` of `0.2.0`, while release v1.0.0 shipped an asset named
`PrusaToOrca-v0.2.0.exe`. A fresh install permanently reported that an update was
available. `version.py` is now the single source of truth, and the release
workflow refuses to publish when the git tag disagrees with it.

## What the app does on your machine

Reads the `.ini` files you select, writes the bundle where you tell it to. One
network request, only when you click "Check for updates", to read the latest
release tag from `api.github.com`. No telemetry, no uploads, no background
activity.

Full detail: [SECURITY.md](https://github.com/La-Dosette/PrusaToOrca/blob/main/SECURITY.md)

## Install

Download `PrusaToOrca-v1.1.0-windows.zip`, unzip it anywhere, run
`PrusaToOrca.exe`. No Python required.
